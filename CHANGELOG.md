## [Unreleased]

### Added
- Full product vision and creative brief in `VISION.md`
- Professional `README.md` with project overview, core experience, design principles, and planned tech stack
- MIT `LICENSE`
- `CONTRIBUTING.md` with contribution guidelines
- `CODE_OF_CONDUCT.md` (Contributor Covenant v2.1)
- `.gitignore` covering common Node, Python, editor, and OS artifacts
- `.env.example` as a safe-to-commit environment variable template
- GitHub issue templates: bug report and feature request
- GitHub pull request template
- Starter CI workflow (`.github/workflows/ci.yml`)

### Concept
- Named the project **Phosphene** — a living visual cosmos where logged moments of happiness become glowing, connected nodes on an infinite dark canvas
- Defined dual experience: private personal constellation + shared collective cosmos accessed via continuous zoom
- Established core design principles: wonder first, nothing is lost, no noise, earn complexity, private by default
